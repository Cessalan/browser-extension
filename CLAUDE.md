# CLAUDE.md

A Chrome Manifest V3 browser extension. Plain HTML/CSS/JS, no build step yet.

- `manifest.json`: extension config
- `popup.html` / `popup.js` / `popup.css`: toolbar popup
- `background.js`: service worker

Test by loading the folder unpacked at `chrome://extensions` (Developer mode).
This project is unrelated to NurseQuizAI.
